# 🎨 FolioMentor – Portfolio Review & Creative Mentorship

## 📌 Project Overview
FolioMentor is a web-based portfolio review and creative mentorship platform designed to connect designers, students, and creative professionals with experienced industry mentors.

The platform allows users to create and manage their portfolios, explore mentors from different creative domains, request professional feedback, and track their improvement through structured reviews. Mentors can review submitted projects, provide ratings and suggestions, and help designers strengthen their portfolios.

FolioMentor aims to make professional guidance more accessible and help creative individuals present their work with confidence.

## ✨ Key Features

- **User Authentication:** Registration and login system with separate roles for designers, mentors, and administrators.
- **Designer Dashboard:** Displays portfolio statistics, review requests, received feedback, and suggested mentors.
- **Portfolio Management:** Users can add, edit, and delete projects with descriptions, categories, links, and cover images.
- **Mentor Discovery:** Browse mentors, search by name or experience, and filter by creative domain.
- **Review Requests:** Designers can select a project, choose a mentor, and submit specific questions or feedback requests.
- **Structured Mentor Feedback:** Mentors can provide detailed comments, improvement suggestions, and portfolio ratings.
- **Feedback Tracking:** Designers can monitor review progress, view completed feedback, rate its usefulness, and ask follow-up questions.
- **Learning Resources:** Provides portfolio improvement tips and links to creative communities and design institutions.
- **Profile Management:** Users can update their personal information, expertise, experience, and biography.
- **Admin Dashboard:** Administrators can monitor users, projects, mentor performance, and review statistics.
- **CSV Report Export:** Admins can download review data and feedback quality reports.
- **Shareable Portfolio:** Designers can copy a link to share their portfolio with others.
- **Responsive Interface:** Clean, modern layout designed to work across different screen sizes.
- **Browser-Based Storage:** Uses localStorage to save user accounts, projects, reviews, and other application data.

## 🎯 Project Objectives

- Create a platform that connects emerging designers with experienced creative professionals.
- Help designers improve their portfolios through structured and actionable feedback.
- Make mentor discovery easier through domain-based filtering and search.
- Provide a simple way to manage projects and track review progress.
- Encourage continuous learning and professional development.
- Build an organized mentorship experience for different creative fields.

## 🛠️ Tools & Technologies

- **HTML5:** Used to structure the web application and its content.
- **CSS3:** Used for styling, responsive layouts, cards, navigation, and visual effects.
- **JavaScript:** Handles application logic, authentication, project management, mentor interactions, and page navigation.
- **LocalStorage:** Stores application data directly in the browser.
- **File API:** Used to upload and process portfolio cover images.
- **Canvas API:** Used to resize and compress uploaded images.
- **Blob API:** Used to generate downloadable CSV reports.
- **Google Fonts:** Uses the Segoe UI/system font stack for a clean interface.

## 📦 Project Deliverable

A browser-based creative mentorship platform where designers can:

- Build and manage their digital portfolios.
- Discover mentors across different creative domains.
- Request reviews and receive structured feedback.
- Track their progress and ask follow-up questions.
- Access portfolio development resources.
- Share their portfolio through a generated link.

Mentors can review submitted projects and guide designers, while administrators can manage platform data and monitor overall activity.
